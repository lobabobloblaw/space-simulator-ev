# Tracker module licensing — UNKNOWN

The tracker modules below ship in `docs/music/` and are wired into the in-game
radio via `docs/js/data/radioPlaylist.js`. Their provenance and licence terms
were not recorded when they were added to the repo and have not since been
established.

- `fx-poly1.mod`
- `glitch_abuse.xm`
- `k_jose_-_a_light_waltz.it`
- `k_jose_-_fruity_radioactivity.s3m`
- `midnight_drive.xm`
- `napping_on_a_cloud.xm`
- `subterrain.xm`

**Action required before any public/commercial release**: for each file,
either (a) locate its original source (module archive, artist page) and
confirm a licence that permits redistribution in this project, recording that
licence here, or (b) replace the file with a track of known, compatible
licence. Until then, treat these as unlicensed and do not represent the game
as fully open-source/redistributable on the strength of its code licence
alone.

See `EVOLUTION_ROADMAP_2026-09.md` §2.5 (S10) and §3.3 for the audit finding
and the plan to replace this catalog with generated, house-licensed beds.
